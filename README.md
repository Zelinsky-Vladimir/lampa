# Svitok

Читалка книг для Windows, macOS и Linux. Книга открывается одной непрерывной лентой: никаких страниц, просто листаете вниз.

## Возможности

- **Форматы:** FB2, FB2.ZIP, EPUB, TXT.
- **Кодировки определяются сами:** UTF-8, windows-1251, KOI8-R/U, CP866 и другие. Старые русские и украинские книги открываются без кракозябр.
- **Бесконечная прокрутка:** книга целиком в одной ленте.
- **Страницы:** страница равна 1800 знакам, как в печатной книге, поэтому номер не меняется от шрифта и размера окна. Номер страницы и общее количество показаны в нижней панели, в оглавлении и в библиотеке.
- **Нижняя панель прогресса:** ползунок по всей книге с отметками глав; при перетаскивании видны страница и глава.
- **Переход к странице:** щёлкните по номеру страницы (или `Ctrl+G`), введите нужный, Enter.
- **Поиск по книге:** список совпадений со страницей и главой, подсветка в тексте, переход стрелками или `Enter`. Регистр и «ё/е» не важны.
- **Запоминает страницу**, на которой вы остановились. На главном экране кнопка «Продолжить · стр. N».
- **Кнопка «← Вернуться»** после перехода по ссылке, поиску или ползунку.
- **Темы:** светлая, сепия, олива, мята, графит, ночь, OLED и своя с любыми цветами.
- **Оформление:** шрифт, размер, межстрочный интервал, ширина колонки, выравнивание, красная строка.
- **Оглавление** с подсветкой текущей главы.
- **Сноски** всплывают поверх текста, никуда не надо прыгать.
- **Автопрокрутка** с регулировкой скорости.
- **Недавние книги** с обложками и прогрессом на главном экране.
- **Открытие** перетаскиванием файла в окно, через «Открыть с помощью» или двойным кликом по .fb2/.epub после установки.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` / `PgDn` | страница вниз |
| `Shift+Пробел` / `PgUp` | страница вверх |
| `↑` `↓` | прокрутка на пару строк |
| `Home` / `End` | в начало / в конец |
| `Ctrl+F` | поиск; `Enter` / `Shift+Enter` или `F3` / `Shift+F3` — следующее / предыдущее |
| `Ctrl+G` | перейти к странице |
| `T` | оглавление |
| `S` | оформление |
| `A` | автопрокрутка, `[` `]` — скорость |
| `Ctrl` + `+` / `−` / `0` | размер шрифта |
| `Ctrl+O` | открыть книгу |
| `F11` | полный экран |
| `Esc` | закрыть панель / сноску |

## Запуск из исходников

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
npm install
npm start
```

Открыть сразу конкретную книгу: `npm start -- путь/к/книге.fb2`.

## Сборка

```bash
npm run dist
```

Готовые файлы появятся в `dist/`. Каждая система собирает только под себя:

- **Windows:** установщик `Svitok Setup x.y.z.exe` и переносная версия `Svitok-x.y.z-portable.exe`
- **macOS:** `.dmg` для Apple Silicon и Intel
- **Linux:** `.AppImage`

### Сборка под все системы через GitHub

В репозитории настроен GitHub Actions (`.github/workflows/build.yml`). Чтобы выпустить релиз:

```bash
git tag v0.1.0
git push origin v0.1.0
```

GitHub соберёт версии для Windows, macOS и Linux и выложит их во вкладку **Releases**. Собрать без релиза можно кнопкой **Run workflow** во вкладке **Actions**.

Сборки не подписаны сертификатом, поэтому:

- **Windows** SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- **macOS** при первом запуске: правый клик по приложению → «Открыть».

## Устройство

```
main.js          главный процесс Electron: окно, диалоги, чтение и распаковка файлов
preload.js       узкий мост между окном и главным процессом
src/decode.js    определение кодировки
src/parsers.js   разбор FB2 / EPUB / TXT в безопасный DOM
src/app.js       интерфейс: лента, темы, оглавление, сноски, прогресс
src/styles.css   оформление
```

Содержимое книг не вставляется как HTML: каждый элемент создаётся заново по белому списку, поэтому скрипты, iframe и обработчики событий из EPUB в окно не попадают. Окно работает в песочнице (`sandbox`, `contextIsolation`) под строгой политикой CSP.
